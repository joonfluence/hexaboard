# Feature Specification: 웹 태그·필터·정렬 UI

**Status**: 구현 완료 (2026-09-21, TC-UI 49건 통과)

참조: [component_spec 01~03](../../docs/component_spec.md), [test_cases/04-ui](../../docs/test_cases/04-ui.md), 005·006·007·008.

## 범위

보류했던 UI-C06(TagBadge), UI-C08의 태그 편집, UI-C09(FilterBar), UI-C10(ColumnSortMenu). TC-UI-007·017~026.

## 결정 (D-101)

- 태그: 카드에 태그 배지, 상세 모달에 태그 입력(Enter 또는 "태그 추가"로 추가, 칩의 "제거"로 삭제, 화면에서는 공백 제거·소문자로 미리 정규화). 태그가 바뀌면 `tags` 전체를 보낸다. 표시는 서버가 돌려준 이름이다.
- 필터 바(보드 상단): 검색어 입력(250ms 디바운스), 우선순위 체크박스(여러 개면 OR), 태그 칩 토글(태그 후보는 **필터 없는 목록**에서 뽑는다, 여러 개면 OR), "필터 해제". 마감일 조건은 없다(D-65). 조건은 서버 쿼리(`q`, `priority`, `tag`)로 실행한다.
- 정렬 메뉴(컬럼 헤더): "정렬" 버튼 → 기준(우선순위/마감일)·방향(오름/내림) 선택 → "실행" → `POST /sort` 뒤 목록 재조회. **필터가 켜진 동안 정렬 버튼 비활성**(D-57). 실행 취소 요소 없음.
- 필터 중에도 드래그 이동은 가능하다(보이는 카드를 기준으로 앞/뒤를 보내면 서버가 숨은 이웃을 고려해 계산). 이동의 낙관적 업데이트는 현재 표시 중인 목록에 적용한다.
