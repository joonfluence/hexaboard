# 테스트 케이스 04. 프론트엔드 UI 컴포넌트

Vitest + Testing Library 컴포넌트 테스트 케이스다 (D-71, E2E는 2차). 컴포넌트 명세는 [component_spec.md](../component_spec.md)에 있고 규칙은 [test_cases.md](../test_cases.md)를 본다. `apps/web`(기능 005)에서 구현하며 상태 표기는 ✅ 완료, ⏳ 예정이다. **표시 방식이 미정인 항목은 "표시 방식 미정"으로 두고 동작만 검증한다.**
