## 진행 우선순위

기준: 첫 구현(첫 마이그레이션, 첫 API 계약)에 들어가서 나중에 바꾸기 비싼 것을 먼저 정한다. 항목의 상세는 아래 주제별 목록에 있다.

| 순위 | 항목 | 이유 |
|------|------|------|
| 구현 시 확정 | 스키마·필터 파라미터 | 해당 코드를 쓰는 시점에 정한다 |
| 낮은 우선순위 | 응답 시간 목표, 다중 인스턴스 마이그레이션 경합 | 현재 규모에서 영향이 작다 |
