# 사용자 스토리

사용자는 개발자 본인 한 명이다. 기능 요구사항과의 연결은 [requirements.md](requirements.md)의 추적 매트릭스를 본다.

| ID | 사용자 스토리 | 관련 기능 |
|----|---------------|-----------|
| US-01 | As a **개발자(본인)**, I want to **새 티켓을 추가**, so that **해야 할 일을 놓치지 않고 기록할 수 있다**. | FR-01, FR-02 |
| US-02 | As a **개발자(본인)**, I want to **티켓을 조회/수정/삭제**, so that **목록을 최신 상태로 유지할 수 있다**. | FR-01 |
| US-03 | As a **개발자(본인)**, I want to **티켓에 마감일을 지정**, so that **기한이 임박한 일을 먼저 처리할 수 있다**. | FR-05 |
| US-04 | As a **개발자(본인)**, I want to **티켓에 우선순위를 매김**, so that **중요한 일을 먼저 확인할 수 있다**. | FR-06 |
| US-05 | As a **개발자(본인)**, I want to **티켓에 태그를 붙여 분류**, so that **관련된 일들을 묶어서 볼 수 있다**. | FR-07 |
| US-06 | As a **개발자(본인)**, I want to **티켓을 검색하고 필터링**, so that **항목이 많아져도 원하는 티켓을 빠르게 찾을 수 있다**. | FR-08 |
| US-07 | As a **개발자(본인)**, I want to **기준을 골라 카드를 정렬**, so that **우선순위나 마감이 급한 순으로 한 번에 정리할 수 있다**. | FR-09 |
| US-08 | As a **개발자(본인)**, I want to **카드를 다른 컬럼으로 드래그해 상태를 변경**, so that **각 일의 진행 상황을 추적할 수 있다**. | FR-02, FR-03, FR-04 |
| US-09 | As a **개발자(본인)**, I want to **같은 컬럼 안에서 카드 순서를 직접 지정**, so that **내가 정한 처리 순서를 화면에 그대로 둘 수 있다**. | FR-04 |

## 범위 밖 시나리오

반복 티켓, 하위 티켓, 알림, 로그인/멀티 유저는 2차 범위라 시나리오를 작성하지 않았다. ([PRD.md](PRD.md#3-2차-제외-범위))
