# 와이어프레임 참고

와이어프레임 산출물(Figma, 이미지)은 아직 없다. 지금까지 정해진 UI 방향만 적는다. 세부 화면은 정해지는 대로 이 문서에 추가한다.

## UI 방향

- **화면 구조**: 상태별 보드형. `TODO` / `IN_PROGRESS` / `DONE` 3개 컬럼에 티켓 카드를 배치한다.
- **참조 디자인**: 전체 UI와 디자인은 Trello를 참조한다. Trello는 컬럼이 사용자 정의지만 이 앱은 상태 3개로 고정이다.
- **상호작용**: 카드를 드래그해 컬럼 간 이동(상태 변경)과 컬럼 안 순서 지정을 한다. ([FR-03, FR-04](functional_requirements.md))
- **목적**: 상태 기반 프론트엔드 UI(드래그, 낙관적 업데이트) 연습

## 화면 개요 (구조만 표시, 세부 미정)

```
┌───────────────────────────────────────────────────┐
│  검색 / 필터 (상단 바)                            │
├───────────────┬───────────────┬───────────────────┤
│ TODO          │ IN_PROGRESS   │ DONE              │
├───────────────┼───────────────┼───────────────────┤
│ [카드]        │ [카드]        │ [카드]            │
│ [카드]        │               │                   │
│ [카드]        │               │                   │
└───────────────┴───────────────┴───────────────────┘
```

## UI 구현 도구

| 영역 | 선택 |
|------|------|
| 스타일링 | Tailwind CSS |
| 컴포넌트 | shadcn/ui (Trello 느낌은 직접 스타일링) |
| 드래그 앤 드롭 | dnd-kit (보드 로직은 직접 조립) |

패키지 버전과 유지보수 상태는 구현 시 공식 문서로 확인한다.

## 화면 목록

| 화면/요소 | 상태 |
|-----------|------|
| 상태별 보드 | 확정 |
| 티켓 생성 | 확정: 컬럼 하단 인라인 입력(제목만). 나머지 필드는 상세 모달에서 편집 |
| 카드 상세 보기·편집 | 확정: 카드 클릭 시 상세 모달 |
| 카드에 표시할 정보 | 확정: 제목 + 우선순위·마감일·태그 배지 |
| 검색·필터 | 확정: 보드 상단 바 (조건 조합은 [FR-08](functional_requirements.md)) |
| 정렬 실행 | 확정: 컬럼 헤더 메뉴 (컬럼 단위 정렬이므로) |
